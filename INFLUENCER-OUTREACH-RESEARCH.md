## 4. Affiliate Program Setup (LemonSqueezy)

### Recommended Configuration

| Setting | Recommended Value | Rationale |
|---------|------------------|-----------|
| **Commission type** | Percentage | Scales if price changes |
| **Commission rate** | 30% ($11.70 per $39 sale) | Industry standard for digital products. Skylum offers 20-45%, Adobe 30%. Our higher rate compensates for lower absolute $ amount. |
| **Cookie duration** | 60 days | Standard is 30 days. 60 days = more generous = more attractive to affiliates. |
| **Minimum payout** | $25 (3 sales) | Low enough to not discourage small affiliates |
| **Payout frequency** | Monthly | Standard |
| **Auto-approve affiliates?** | Manual review | For now, to ensure quality partners |
| **Products included** | Standard license only | Free version shouldn't generate commission |

### Setup Steps in LemonSqueezy

1. Go to **Dashboard > Affiliates > Settings**
2. Set commission to **30% percentage-based**
3. Set cookie/tracking duration to **60 days**
4. Set referral URL to **https://boost.photo** (not storefront)
5. Add **tracking script** to boost.photo `<head>` (from LS docs)
6. Upload **creative assets**: banner ads (728x90, 300x250), product screenshots, logo
7. Write **affiliate welcome email** with key selling points & talking points
8. Create **affiliate landing page** on boost.photo/affiliates with:
   - Commission details
   - Application form
   - Product screenshots & assets they can use
   - Key talking points / USPs

### Creative Assets for Affiliates

Pripravit:
- Product logo (SVG, PNG)
- 3 banner sizes (728x90, 300x250, 160x600)
- Before/after screenshot (static photo vs animated GIF)
- 30-second demo GIF
- Product description (50, 100, 200 words)
- Key bullet points (USPs)
- Discount coupon code template

## 6. Competitor Intelligence

### GIF Delivery (gif.delivery)
- Direct competitor — Lightroom GIF creation tool
- SSL certificate issues on their website (bad sign)
- Limited online presence / reviews found
- **Opportunity:** Weak competitor presence means the "Lightroom GIF plugin" niche is open

### Traditional Workflow (Without Plugin)
- Lightroom edit -> Export JPGs -> Open Photoshop -> Timeline -> Create Frame Animation -> Export GIF
- 10+ steps, requires Photoshop subscription
- **Our pitch:** "One click instead of 10 steps. No Photoshop needed."

### Adjacent Products
- **LRTimelapse** — Timelapse from LR (different use case but similar audience)
- **Flixel Cinemagraph Pro** — $199, pro cinemagraph tool (different market tier)
- **Ashampoo Cinemagraph** — Desktop cinemagraph tool
